Прямой запуск для отладки дробовиков, 14 октября 2026

Скрипт Start-ShotgunTest.ps1 обходит формирование команды Dedicated Server Tool.
Пути проекта, модов и профиля заключены в кавычки. Моды и игровые настройки не меняются.
Проверены синтаксис и режим DryRun клиента. Сервер/клиенты агентом не запускались.

В PowerShell открой эту папку.
Проверка команды без запуска: .\Start-ShotgunTest.ps1 -Role Client -DryRun
Проверка загрузки Sounds: .\Start-ShotgunTest.ps1 -Role Client -Test SoundsOnly
Без сервера соединение не состоится, но загрузка модов видна в журнале до соединения.

Для сервера нужны -Role Server и -ServerExecutable с его фактическим полным путём.
Добавь -DryRun для предварительной проверки. Не подставляй клиент или Workbench.
Серверный файл в проверенной стандартной библиотеке Steam пока не найден.
Для полной проверки после запуска сервера: .\Start-ShotgunTest.ps1 -Role Client
Второй клиент: .\Start-ShotgunTest.ps1 -Role Client -ClientNumber 2

Профили изолированы: ARMST_Shotgun_DirectServer_ARMST и ARMST_Shotgun_DirectClient_ARMST_1.
Сервер запускается скрыто. Скрипт выводит PID: завершай только этот процесс после теста.
Порты, маршрутизатор и брандмауэр не меняются. Не публикуй отладочный сервер в интернете.
Если Windows запрещает ps1, не меняй глобальную политику выполнения: сообщи ошибку.
Исправление кавычек само по себе не гарантирует исправления ошибки пакета Sounds.
