### Behaviour
- `ARMST_T4B_WeaponProbe.OnPostInit`: identifies the lab weapon, sets the installed magazine
  baseline (`m_iT4BStartAmmo`, 0…max), logs `phase=init` / `phase=baseline`; a single bounded
  deferred retry (max 4 × 250 ms) handles init ordering; no infinite polling.
- `ARMST_T4B_AddRoundWeaponAction.PerformAction(owner, user)` (shown as **"T4b: +1 into installed
  mag"**):
  - guards (reject without write): no weapon → `no-weapon`; weapon lacks the T4b probe →
    `not-lab-weapon`; no installed magazine → `no-installed-magazine`; one-shot latch →
    `already-used`; `ammo >= max` → `full`; `ammo < 0` → `bad-ammo`.
  - otherwise one direct `mag.SetAmmoCount(old+1)`, then immediate read-back of
    `GetCurrentMagazine()` identity, `GetOwner()`, `GetAmmoCount()`, muzzle/chamber.
  - logs `[ARMST_T4B-INSTALLED] #n phase=pre|post|reject …` with `sameMagazine`, `sameOwner`,
    `chamberUnchanged`, `want`, `got`, weapon/mag entity keys and `srv`.
  - no `Spawn/Attach/Detach/Despawn/MagRelease`, no `ClearChamber`, no donor, no inventory,
    no spawn/delete, no RPC, no global `modded`, no input listener.

## 4. Owner run steps

1. Loadout: base engine + `ARMST-PLATFORM---Weapons` + **`ARMSTMP133T4B_InstalledMagProbe`**;
   T4a, Core, V2/P2, Astra **OFF**.
2. **Workbench check first:** the lab weapon's `ARMST_T4B_AddRoundWeaponAction` must show
   `Parent Context List (1): default` and the label; the probe component present; `ActionsManagerComponent`
   is the single inherited one. STOP if the context is empty or the action is missing.
3. Compile `Game` (STOP on own `SCRIPT(E)`).
4. Place **one** lab weapon; confirm `[ARMST_T4B-INSTALLED] #0 phase=init/baseline … ammo=0/10`
   and that the magazine is **installed** (weapon HUD shows 0/10).
5. Invoke the weapon's contextual action **"T4b: +1 into installed mag"** once → expect
   `phase=pre ammo=0/10` → `phase=post got=1 sameMagazine=1 sameOwner=1 chamberUnchanged=1`.
6. Invoke again → `phase=reject reason=already-used`.
7. Full case: set the probe's `m_iT4BStartAmmo=10`, re-enter, invoke → `phase=reject reason=full`.
8. Send the `[ARMST_T4B-INSTALLED]` excerpt + the Workbench properties screenshot + visible HUD.

## 5. Unsafe / STOP conditions

STOP and report a log if: `GetCurrentMagazine()` is null, the magazine is replaced
(`sameMagazine=0`/`sameOwner=0`), the chamber changes (`chamberUnchanged=0`), another weapon's
actions change, a lab `SCRIPT(E)` appears, or no distinct lab identity is shown. Do not test
during a reload/animation/weapon switch (no SDK guard exists).
