## 0. Открытие проекта (один раз)

1. Запусти **Arma Reforger Tools / Workbench**.
2. Game Project Manager → **Add Existing** →
   `C:\Users\yshky\Documents\My Games\ArmaReforgerWorkbench\addons\ARMST_MP133_AnimationLab\addon.gproj`.
3. Дождись загрузки/компиляции. Открой `logs\<свежая папка>\script.log` и проверь,
   что `ARMST_MP133_Lab_Component.c` и `ARMST_MP133_Lab_Character.c` **без ошибок**.
4. (Опционально) Animation Editor → открой `MP133_Lab.aw` из вкладки
   `Assets/Weapons_RUS/Mp_133/Workspace/` — график должен открыться; новый узел
   InsertSingleProjectile самозацикливается по `BlendOut` при
   `CMD_Weapon_Reload == 7`.

## 1. Тестовая сцена

5. World Editor → открой `Worlds/MP133_Lab/MP133_Lab.ent`
   (слой `MP133_Lab_Layers/default.layer` подхватится сам). Пресс Play.
6. На земле: **MP 133 (LAB)**, **MP 133 RIS (LAB)**, трубчатые магазины

7. Собери оружие: подними дробовик, «перетащи» трубчатый магазин в слот
   (как обычно для магазинов) — либо обычным способом из инвентаря.

## 2. Управление в тесте

| Действие | Клавиша |
|---|---|
| Дослать ОДИН патрон в трубу (добавить в трубчатый магазин) | **H** (зажать = повторять, пока можно) |
| Помповый цикл (дослать патрон в ствол / перезарядка после выстрела) | **LSHIFT+R** (существующее ARMST-действие) |
| Обычная перезарядка (смена трубчатого магазина) | **R** — в лаборатории НЕ использовать |

`ARMST_MP133_LAB_INSERT` уже привязана к `H` в
`Configs/System/chimeraInputCommon.conf` аддона.

## 3. Проверки (отмечай результат напротив каждого шага)

### A. Базовое
- [ ] A1. Подъём/идл: корректная поза дробовика, без «рваных» поз.
- [ ] A2. Выстрел с патроном в трубе: анимация отдачи, патрон расходуется (счётчик трубы −1).
- [ ] A3. Выстрел с пустой трубой: щелчок, без выброса и без «придуманного» патрона.

### B. Помпа (LSHIFT+R)
- [ ] B1. После выстрела помпа двигает цевье; **ровно один** патрон переходит
      из трубы в ствол (труба −1 на каждый помповый цикл, без двойного списания).
- [ ] B2. Помпа с пустой трубой: патрубок чистый, счётчик не уходит в минус.

### C. Досылка патронов (H)
- [ ] C1. Начало: однократное нажатие H → один цикл вставки, труба +1, резерв −1.
- [ ] C2. Удержание H → циклы повторяются: каждые ~3,3 с труба +1, пока резерв/ёмкость позволяют.
- [ ] C3. Труба «полна» (по умолчанию 2): циклы останавливаются, «призрачных» патронов нет.
- [ ] C4. Резерв 0: циклы останавливаются, патрон не добавляется.
- [ ] C5. Ёмкость: при необходимости поменяй на префабе `armst_Shotgun_mp_133_Lab.et`
      → `ARMST_MP133_Lab_Component` → `m_iTubeCapacityOverride` (0 = правило ARMST, т.е. 2).

### D. Прерывания
- [ ] D1. Отпускание H в середине цикла: без «полувставленного» и без потерянного патрона.
- [ ] D2. Выстрел/помпа во время досылки: чистое прерывание, никаких лишних патронов.
- [ ] D3. Опускание оружия / смена оружия / экипировка обратно: восстановление, нет залипших состояний.
- [ ] D4. Полный цикл «досылка → помпа в ствол → выстрел»: число патронов сходится
      (труба + ствол + резерв = константа на протяжении всех операций).

### E. Сетификация
- [ ] E1. В соло (клиент=сервер) счётчики совпадают с логами
      `[ARMST_MP133_LAB] Insert COMMIT: tube %1 -> %2, reserve %3`
      (включи `m_bLabDebugLog 1` на префабе).
- [ ] E2. Повторный/переигранный эвент не добавляет патрон дважды (cooldown 500 мс).

## 4. Опционально: санитизированные клипы (убрать magazine-swap события)

9. Animation Editor → импортируй по очереди
   `Assets/Weapons_RUS/Mp_133/Workspace/LabClips/W_MP133_Lab_Inject.txa` и
   `P_MP133_Lab_Inject.txa` (это копии оригинальных движений, только события
   переименованы в `ARMST_Lab_Shell_*`). После первого импорта Workbench
   создаст `.anm` — тогда можно заменить в `MP133_Lab_weapon.asi` /
   `MP133_Lab_player.asi` строки `Reload_InsertMag` на эти клипы. По умолчанию
   лаборатория работает и с оригинальными клипами.
